# BIGMOTHER Mobile
A runnable React Native / Expo prototype for childcare centre compliance and communication.

## Included
- AI-style compliance overview and requirement drill-down
- Staff qualification/certificate tracker and reminder interactions
- Educator voice-note recording (native Expo Go on iOS/Android)
- Quick child observations and learning feed
- Daily student timetable
- Family learning-story and two-way messaging UI
- Language selector (English, Spanish, Hindi demo)
- Mobile-first accessible navigation

## Run
1. Install Node.js 18+.
2. In this folder run: `npm install`
3. Run: `npx expo start`
4. Scan the QR code with Expo Go on your phone, or press `a` for Android emulator / `i` for iOS simulator (macOS).

## Important prototype boundary
This version intentionally uses local demo state. Before real childcare use, add secure authentication/role permissions, encrypted backend storage, consent/media controls, audited regulatory data ingestion, server-side AI with citations, and production push notifications. Do not use demo compliance summaries as legal/regulatory advice.
