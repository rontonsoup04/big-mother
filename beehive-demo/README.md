# BEEHIVE static prototype

This folder contains the exact HTML, CSS, and JavaScript prototype currently deployed.

## Add it to the Big Mother Next.js repository

1. Extract the `beehive-demo` folder into the repository's `public/` directory.
2. Commit and push the folder to a feature branch.
3. After the branch is merged and deployed, open `/beehive-demo/index.html`.

The demo uses browser localStorage only. Do not enter real child medical information. It has no production authentication, secure storage, OCR, or live SMS/email.
